# Huistaak: mee te brengen op woensdag 18 november

> Er zijn drie weken zonder les (4 en 11 november vallen weg).
> Deze opdracht is je oefening in die periode. Reken op twee tot drie uur.

Je werkt één zelfgekozen opdracht volledig uit, volgens de aanpak van de module.
Wat je maakt is minder belangrijk dan **hoe** je het maakt.

---

## Kies een opdracht

Neem iets dat je zelf nuttig vindt. Drie suggesties, maar een eigen idee is beter:

- **Kastickets**: je geeft bedragen in, het programma toont totaal, gemiddelde, duurste,
  en hoeveel er boven een grens zitten.
- **Uren bijhouden**: per dag een aantal uren ingeven, het programma toont het weektotaal,
  het gemiddelde per dag, en of je boven of onder je streefdoel zit.
- **Woordenteller**: je geeft een stuk tekst in, het programma toont het aantal woorden,
  de unieke woorden, en de tien meest voorkomende.

Iets uit je eigen werk mag ook, en is meestal leuker om te maken.

## Wat je inlevert

Eén map met daarin je `.py`-bestand(en) en een kort `README.md`.

### 1. De analyse (in je README.md)

| | |
|---|---|
| Wat gaat erin? | |
| Wat komt eruit? | |
| Wat kan er misgaan? (minstens vijf randgevallen) | |

### 2. De opsplitsing (in je README.md)

Je opdracht in 3 tot 6 taken, en per taak of het must, should of could was.

### 3. Je Definition of Done (in je README.md)

Vier tot zes punten. Vink op het einde af wat gelukt is en wat niet. **Niet alles hoeft
gelukt te zijn**, eerlijk afvinken is meer waard dan alles afvinken.

### 4. De code

- Stappen als commentaarregels, code ertussen
- **Minstens drie functies** met een duidelijke naam en een `return`
- Geen stuk code dat twee keer bijna hetzelfde is

### 5. Je testtabel (in je README.md)

| Invoer | Wat ik verwachtte | Wat er gebeurde |
|---|---|---|

Test met minstens acht waarden, waarvan de helft randgevallen. Fouten die je nog niet kan
opvangen zijn **geen probleem**, noteer gewoon wat er gebeurt. Opvangen leren we in les 7.

### 6. AI-verantwoording

Heb je AI gebruikt: noteer waarvoor, en hoe je gecontroleerd hebt dat het klopte.

## Waarop gelet wordt

Dit is geen examen en er staan geen punten op. Maar het is de beste voorbereiding op de
moduleproef van 25 november, want die volgt exact dezelfde structuur.

Kom je vast te zitten: **noteer waar en waarom, en breng dat mee.** De vastlopers van de klas
zijn het lesmateriaal van les 7. Een opdracht die halverwege strandt met een goede notitie
erover is nuttiger dan een afgewerkte opdracht zonder.
